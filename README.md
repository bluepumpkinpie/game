# ✨ Легенда Ночного Замка - 2D Point & Click Adventure ✨

Добро пожаловать в магическую приключенческую игру в жанре point-and-click с аниме персонажами!

## 📖 Описание

Это атмосферная 2D point-and-click приключенческая игра в стиле **ночного замка** с **аниме персонажами**, созданная на HTML5 Canvas и JavaScript. Вы исследуете древний замок под лунным светом, знакомитесь с загадочными персонажами, собираете магические предметы, решаете головоломки и раскрываете легенду о сокровище.

## 🎯 Цель игры

Найдите легендарное сокровище, спрятанное в древнем замке! Исследуйте комнаты, общайтесь с персонажами-хранителями, собирайте магические предметы и используйте их правильно, чтобы раскрыть все тайны.

## 🕹️ Как играть

### Управление:

1. **Осмотреть** - Нажмите кнопку "Осмотреть" и кликните на объект, чтобы получить его описание
2. **Взять** - Нажмите кнопку "Взять" и кликните на предмет, чтобы добавить его в инвентарь
3. **Использовать** - Выберите предмет из инвентаря и используйте его на объектах в комнате
4. **Перемещение** - Кликайте на двери со стрелками для перехода между комнатами

### Инвентарь:

- Собранные предметы появляются внизу экрана
- Кликните на предмет в инвентаре, чтобы выбрать его
- Выбранный предмет подсвечивается золотым цветом
- Используйте предметы на объектах для решения головоломок

## 🌙 Особенности

### Визуальный стиль
- **Атмосфера ночного замка** с темной готической палитрой
- **Луна и звезды** в окнах комнат
- **Каменные стены замка** с детальной текстурой
- **Магическое освещение** и эффекты свечения
- **Анимированные звезды** на фоне страницы

### Аниме персонажи
- **Юки** - Хранительница замка с фиолетовыми волосами (Прихожая)
- **Айка** - Мудрая библиотекарша с зелеными глазами (Библиотека)
- **Рей** - Призрачный дух замка (Секретная башня)
- Уникальная цветовая палитра для каждого персонажа
- Система диалогов - общайтесь, чтобы получить подсказки!

### Игровые механики
- Рисование персонажей в аниме стиле прямо на Canvas
- Плавная анимация (60 FPS)
- Интерактивные диалоги с персонажами
- Система подсказок через NPC

## 🗺️ Локации

Игра содержит три мистические локации:

- **Прихожая Замка** - Входной зал с круглым окном и Юки-хранительницей
- **Библиотека Замка** - Огромная библиотека с древними книгами и Айкой
- **Секретная Башня** - Таинственная башня под звездным небом с духом Рей

## 🚀 Запуск игры

### Способ 1: Локально

1. Скачайте все файлы
2. Откройте `index.html` в любом современном браузере
3. Наслаждайтесь игрой!

### Способ 2: Локальный сервер

```bash
# Используя Python 3
python -m http.server 8000

# Или используя Python 2
python -m SimpleHTTPServer 8000

# Или используя Node.js
npx http-server
```

Затем откройте браузер и перейдите по адресу `http://localhost:8000`
