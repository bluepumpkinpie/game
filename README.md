# 🎮 Тайна Старого Особняка - 2D Point & Click Adventure

Добро пожаловать в увлекательную приключенческую игру в жанре point-and-click!

## 📖 Описание

Это классическая 2D point-and-click приключенческая игра, созданная на HTML5 Canvas и JavaScript. Вы исследуете старый особняк, собираете предметы, решаете головоломки и раскрываете тайны.

## 🎯 Цель игры

Найдите сокровище, спрятанное в особняке! Исследуйте комнаты, собирайте предметы и используйте их правильно, чтобы решить все головоломки.

## 🕹️ Как играть

### Управление:

1. **Осмотреть** - Нажмите кнопку "Осмотреть" и кликните на объект, чтобы получить его описание
2. **Взять** - Нажмите кнопку "Взять" и кликните на предмет, чтобы добавить его в инвентарь
3. **Использовать** - Выберите предмет из инвентаря и используйте его на объектах в комнате
4. **Перемещение** - Кликайте на двери со стрелками для перехода между комнатами

### Инвентарь:

- Собранные предметы появляются внизу экрана
- Кликните на предмет в инвентаре, чтобы выбрать его
- Выбранный предмет подсвечивается золотым цветом
- Используйте предметы на объектах для решения головоломок

## 🗺️ Локации

Игра содержит несколько локаций:

- **Прихожая** - Начальная локация со столом и картиной
- **Библиотека** - Комната с книжными полками и письменным столом
- **Секретная комната** - Скрытая комната с важными подсказками

## 💡 Подсказки

1. Внимательно осматривайте все объекты
2. Некоторые предметы можно использовать на других предметах
3. Читайте описания - они содержат подсказки
4. Не все предметы можно взять сразу
5. Исследуйте все комнаты

## 🚀 Запуск игры

### Способ 1: Локально

1. Скачайте все файлы
2. Откройте `index.html` в любом современном браузере
3. Наслаждайтесь игрой!

### Способ 2: Локальный сервер

```bash
# Используя Python 3
python -m http.server 8000

# Или используя Python 2
python -m SimpleHTTPServer 8000

# Или используя Node.js
npx http-server
```

Затем откройте браузер и перейдите по адресу `http://localhost:8000`
