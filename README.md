# ✨ Легенда Ночного Замка - 2D Point & Click Adventure ✨

Добро пожаловать в магическую приключенческую игру в жанре point-and-click с аниме персонажами, созданную на **Godot Engine 4.2**!

## 📖 Описание

Это атмосферная 2D point-and-click приключенческая игра в стиле **ночного замка** с **аниме персонажами**, созданная на Godot Engine. Вы исследуете древний замок под лунным светом, знакомитесь с загадочными персонажами, собираете магические предметы, решаете головоломки и раскрываете легенду о сокровище.

## 🎯 Цель игры

Найдите легендарное сокровище, спрятанное в древнем замке! Исследуйте комнаты, общайтесь с персонажами-хранителями, собирайте магические предметы и используйте их правильно, чтобы раскрыть все тайны.

## 🎮 Технологии

- **Godot Engine 4.2+** - Игровой движок
- **GDScript** - Язык программирования
- **Canvas Drawing API** - Для рисования аниме персонажей

## 🚀 Запуск игры

### Требования

- [Godot Engine 4.2+](https://godotengine.org/download) (бесплатно, open-source)

### Инструкция по запуску

1. **Скачайте и установите Godot Engine 4.2 или новее**
   - Перейдите на https://godotengine.org/download
   - Скачайте версию для вашей ОС (Windows, Mac, Linux)
   - Установите или распакуйте

2. **Откройте проект**
   - Запустите Godot Engine
   - Нажмите "Import"
   - Выберите файл `project.godot` из папки проекта
   - Нажмите "Import & Edit"

3. **Запустите игру**
   - Нажмите F5 или кнопку "Play" в правом верхнем углу
   - Наслаждайтесь игрой!

### Экспорт игры

Чтобы создать исполняемый файл:

1. В Godot выберите **Project → Export**
2. Добавьте шаблон экспорта для вашей платформы (Windows, Linux, Mac, Web)
3. Настройте параметры экспорта
4. Нажмите "Export Project"

## 🕹️ Как играть

### Управление

1. **Осмотреть** - Нажмите кнопку "ОСМОТРЕТЬ" и кликните на объект для описания
2. **Взять** - Нажмите кнопку "ВЗЯТЬ" и кликните на предмет
3. **Использовать** - Выберите предмет из инвентаря и используйте на объектах
4. **Перемещение** - Кликайте на двери для перехода между комнатами

### Инвентарь

- Собранные предметы появляются в панели инвентаря
- Кликните на предмет, чтобы выбрать его
- Выбранный предмет подсвечивается фиолетовым
- Используйте предметы на объектах для решения головоломок

## 🌙 Особенности

### Визуальный стиль
- **Атмосфера ночного замка** с темной готической палитрой
- **Луна и звезды** в окнах комнат
- **Каменные стены замка** с детальной текстурой

- Персонажи рисуются процедурно через Canvas API Godot
- Уникальная цветовая палитра для каждого персонажа
- Система диалогов - общайтесь для подсказок!

### Игровые механики
- Рисование персонажей в аниме стиле через GDScript
- Система комнат с переходами
- Интерактивные диалоги с NPC
- Система головоломок с предметами
- Инвентарь с drag-and-drop

## 🗺️ Локации

Игра содержит три мистические локации:

- **Прихожая Замка** - Входной зал с круглым окном и Юки-хранительницей
- **Библиотека Замка** - Огромная библиотека с древними книгами и Айкой
- **Секретная Башня** - Таинственная башня под звездным небом с духом Рей

## 🔧 Разработка

### Добавление новой комнаты

1. Создайте новую сцену: `scenes/rooms/NewRoom.tscn`
2. Добавьте скрипт `Room.gd`
3. Настройте параметры комнаты (название, описание, цвета)
4. Добавьте персонажей и объекты
5. Создайте выходы в другие комнаты

### Добавление нового персонажа

1. Создайте Node2D в сцене комнаты
2. Добавьте скрипт `AnimeCharacter.gd`
3. Настройте внешность (цвета волос, глаз, одежды)
4. Добавьте диалоги
5. Настройте позицию и масштаб

### Добавление объекта

1. Создайте Node2D в сцене комнаты
2. Добавьте скрипт `InteractableObject.gd`
3. Настройте параметры (размер, цвет, описание)
4. Настройте взаимодействия с другими предметами
